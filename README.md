# 关键创新点
1. RIR 全物理建模
```matlab
ht = rir_generator(c, fs, rm, s_target, L, beta, nsample, ...);
```
- 不依赖人为设定的延迟表
- 房间反射、混响、衰减等全自动生成
- 关键参数
    - L = [5, 4, 6]：房间尺寸
    - beta = 0：墙体反射系数（可调混响）
    - order = -1：镜像源阶数（自动）

2. 导向矢量的近场-远场统一
```matlab
% 近场模型：距离衰减 + 相位
dist_target = norm(mic_pos(m,:) - s_target);
a_target(m,k) = exp(-1j*2π*freq*dist_target/c) / dist;
```
- 关键：不是平面波假设（az/el），而是实际声源到麦克风的几何距离
- 支持任意阵列形状 (非均匀分布可以)
- 支持近场源 (距离近时，幅度衰减 1/r)


3. 自适应协方差矩阵
```matlab
% 滑动窗口平均
Xloc = Xkf(:, t1:t2);           % ±10 帧
Rxx = (Xloc * Xloc') / frames;

% Shrinkage 收缩 (防止过拟合)
R_shrink = (1-α)·Rxx + α·trace(Rxx)/M·I;

% 自适应对角加载 (基于迹数)
reg = ε·trace(Rxx) / M;
Rxx = Rxx + reg·I;
```

- 目的：防止秩亏、数值不稳定、噪声过度放大
- 调参方向：
    - Mavg：滑动窗口大小，越小越 stable
    - epsilon：对角加载系数，越小越 stable
    - shrink_alpha：Shrinkage 收缩系数，对训练数据少时有帮助

4. 诊断系统
- 特征值谱：识别信号vs噪声的能量分布
- 波束图：可视化频率响应方向性
- PSD 对比：目标/干扰的能量变化

# 双支路MVDR

1. 对准目标、抑制干扰，输出目标增强频谱图  
2. 对准干扰、抑制目标，输出干扰增强频谱图  
3. 同时给出 MVDR 处理前后频谱图对比  
4. 修正了原脚本只有单支路 MVDR 的偏差

**MVDR 实现过程（你这份代码当前逻辑）**
1. 多通道 STFT  
对每个麦克风通道做 STFT，得到复频谱 \(S(f,t,m)\)。

2. 构造导向矢量  
根据目标/干扰声源位置与阵列几何，分别构造 \(a_{target}(f)\) 与 \(a_{interf}(f)\)（远场或近场分支）。

3. 协方差估计  
按频点估计协方差矩阵 \(R_{xx}(f)\)，并加对角加载与可选 shrinkage 保稳。

4. MVDR 权重  
每个频点用
\[
w(f)=\frac{R_{xx}^{-1}(f)a(f)}{a^H(f)R_{xx}^{-1}(f)a(f)}
\]
得到权重。  
你现在有两套：
- 目标指向：\(a=a_{target}\)，用于保留目标
- 干扰指向：\(a=a_{interf}\)，用于保留干扰

5. 频域加权与重建  
\[
Y(f,t)=w^H(f)X(f,t)
\]
后做 ISTFT，得到时域输出。现在输出有两路：
- 目标增强输出
- 干扰增强输出

**修正/新增的关键点**
1. 新增双支路分量 STFT：目标、干扰、干扰+噪声、目标+噪声。  
2. 将原单次 MVDR 循环改为双循环：  
- target-steered 分支  
- interference-steered 分支  
3. 新增两路 ISTFT 与性能指标：  
- 目标支路：SNR 改善

# 结果判断

目标抑制/干扰抑制是否成功，不能只看“还看不看得到一条线”，更可靠的是看这三个现象：

1. 目标指向输出里，目标频率那条谱线最亮，干扰频率明显变弱。
2. 干扰指向输出里，干扰频率那条谱线最亮，目标频率明显变弱。
3. PSD 数值上，目标指向输出在干扰频点的功率比输入明显下降，干扰指向输出在目标频点的功率比输入明显下降。

更合适的判据是：
- 目标指向：1 kHz 处保持强，4 kHz 处下降
- 干扰指向：4 kHz 处保持强，1 kHz 处下降
- 如果是定量看，抑制达到 10 dB 左右通常就算比较明显，15 dB 以上会更直观

你现在看到“目标指向频谱里干扰依然明显，干扰指向里目标也明显”，常见有两类原因：

第一类是显示假象，不一定是算法真的失败。  
原来每张 spectrogram 都自动用了自己的颜色尺度，弱残留会被重新拉亮，看上去像“还很明显”。把对比图改成了统一色标，这样更适合判断真实抑制效果。

第二类才是参数和建模问题。可以按这个顺序调：

1. 把 `epsilon` 再降一档  
现在我已经把它从 `1e-3` 改成 `1e-4`。如果还不够，可以继续试 `1e-5`。

2. 把 `shrink_alpha` 设得更小，甚至设成 0  
如果协方差已经比较稳定，shrinkage 反而会把零陷拉浅。现在我已经把它从 `0.05` 降到 `0.01`。

3. 增大协方差滑窗 `Mavg`  
我已经从 21 调到 31。还不够的话可以试 41 或 61，让协方差估计更稳。

4. 先用固定权重，不用时变权重  
如果你开了时变 MVDR，帧间权重切换可能会让结果更“糊”。你现在默认是 `mvdr_use_time_varying = false`，这个先保持。

5. 优先看 PSD，不要只看 spectrogram  
对纯音信号，spectrogram 很容易受色标和窗函数泄漏影响。真正判断抑制，优先看 1 kHz 和 4 kHz 的 PSD 曲线变化。

6. 检查阵列孔径和源位置  
你的阵列孔径只有 0.15 m，虽然 1 kHz 和 4 kHz 理论上能分辨，但实际零陷深度还是受几何影响。如果麦克风坐标、单位、阵列中心有偏差，抑制会明显变差。

如果你要一个更直接的判断标准，可以这样看：
- 目标指向输出里，4 kHz 至少比输入低 10 dB，越低越好
- 干扰指向输出里，1 kHz 至少比输入低 10 dB，越低越好
- 这两个方向上的主频保持得越清楚，说明 MVDR 越成功

# PSD

读取阵列坐标 → 生成目标/干扰到各麦克风的RIR → 卷积得到多通道观测 → STFT域构造导向矢量与协方差 → 计算MVDR权重并输出两路波束结果 → ISTFT重建 → 用波形、时频图、波束图、SNR/ISR与PSD做诊断。代码里还做了远近场判定、对角加载+收缩稳健化、2 kHz/4 kHz定点诊断。  

**PSD 是什么**：功率谱密度（Power Spectral Density），表示“单位带宽上的信号功率”，常见单位是 W/Hz（线性）或 dB/Hz（对数）。脚本里用 `pwelch` 得到 `Pxx`，再画 `10*log10(Pxx+eps)`。  
**大小和正负的含义**：  
1. 线性 PSD `Pxx` 物理上应≥0，越大代表该频率能量越强。  
2. dB/Hz 可以为负，这**不代表负功率**，只代表该值低于参考 1 W/Hz（或归一化参考）；0 dB 表示等于参考，正值高于参考。  

**MVDR 还可用的性能指标**（除你现在已有 SNR/ISR、波束图、PSD 外）：
1. **SINR gain / Array gain**：输入输出信干噪比提升，更直接反映抑制能力。  
2. **输出失真度**：如目标分量保真误差、频谱畸变（LSD）、相位失真。  
3. **语音质量/可懂度**（若是语音）：STOI、PESQ、SI-SDR。  
4. **空间指标**：主瓣宽度、零陷深度（干扰方向）、旁瓣电平、Directivity Index、White Noise Gain（WNG）。  
5. **稳健性指标**：DOA失配、阵列位置误差、混响变化下的性能退化曲线。  

补充一点：你这份代码当前 `noise=zeros(...)`，所以“SNR”本质上更接近**目标对干扰比**；且默认启用了 oracle 协方差选项，属于偏“上界/诊断”设定。

解读核心：看“相对差异”，不是看是否低于0。
PSD 在 0 dB/Hz 以下只说明该频点功率密度小于参考 1，不是异常。

实用解读方法：

同一频点前后对比：After - Before（dB）才是MVDR效果。

看目标频带是否上升（或下降更少）：目标波束在目标频率附近应更高。

看干扰频带是否下降：在干扰频率附近应明显压低。

看动态范围与形状：峰值位置、带宽、旁瓣/底噪变化比“绝对是否<0”更有意义。


一个直观例子：-45 dB/Hz 提升到 -30 dB/Hz，虽然都小于0，但已经是+15 dB改进，这通常是显著增强。
